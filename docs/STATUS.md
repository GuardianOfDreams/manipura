## 1. Общий статус

**MVP работает.** Протестировано на iPhone в Telegram. Гласные меняются, гироскоп работает, интерфейс приятный. Подтверждено Александром.

## 2. Что работает

### 2.1. Движок (WASM)

- Отдельный `manipura.wasm` 32 KB (только синтез, анализатор отрезан).
- 11 экспортов `_manipura_synth_*`: `init`, `set_preset`, `set_f0`, `set_fwidth`, `set_h1_boost`, `set_inharm`, `get_gains`, `render`, `render_block`, `reset_phase`, `morph`.
- `render` даёт PCM, `gains` 1:1 с JS-эталоном (проверено в Node).
- Известный баг: клиппинг (peak до 1.64), нормализован в JS.

### 2.2. Аудио

- 5-voice mix (A, O, U, E + C).
- Нормализация per-vowel (peak -> 0.9).
- Сглаживание 20 мс linear ramp.
- Работает на iPhone в Telegram.

### 2.3. IMU

- `DeviceOrientationEvent.requestPermission()` для iOS 13+.
- 2D-крест (beta, gamma).
- `weightsFromIMU` — 10 кейсов, сумма = 1.00.
- Работает на iPhone.

### 2.4. UI

- Canvas-рендер (ring, ticks, cross, letters, C, dot, line).
- Тёмная янтарная тема.
- Readout (VOWEL, ALPHA, BETA/GAMMA).
- Кнопки Start Sound / Enable Orientation.

### 2.5. Деплой

- GitHub Pages: `https://guardianofdreams.github.io/manipura/`.
- Карточка на титуле QALIMBA (Telegram).
- Протестировано Александром.
